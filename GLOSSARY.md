# Learning notebook

The notebook helps one student practise programming problems with a parent's guidance.

## Language

### Problems and homework

**Problem**:
A programming exercise from LeetCode or Codeforces. A chapter or the library can contain a problem before it is assigned as a homework task.
_Avoid_: Task, assignment.

**Library**:
The collection of problems added to the notebook, together with their work history and progress. A chapter can include problems that are not yet in the library.

**Homework**:
A collection of homework tasks with a title, shared instructions, and an optional due date.
_Avoid_: Homework bundle.

**Homework task**:
An assignment of one problem within homework, with its own work and review state. Each problem has at most one active homework task.
_Avoid_: Problem, task without context.

**Active homework task**:
A homework task that is assigned, in progress, awaiting review, or returned for changes. Completed and cancelled homework tasks are inactive.

**Completed homework task**:
A homework task completed by the parent after review or by a successful hidden-test check. The parent can return it for another attempt.
_Avoid_: Solved problem.

**Submission**:
A record of a saved attempt submitted for a specific homework task. A task can have several submissions, with the latest one used for homework review.
_Avoid_: Attempt, test run.

### Learning material

**Learning set**:
An ordered sequence of chapters about one subject, available through **Бомжарня**.
_Avoid_: Homework, lesson.

**Chapter**:
A unit within a learning set that contains a lesson, problems, reading links, and a quiz deck.
_Avoid_: Lesson, learning set.

**Lesson**:
The teaching text and figures within a chapter.
_Avoid_: Chapter, learning set.

**Quiz card**:
One question in a chapter's quiz, with an expected answer and an explanation.
_Avoid_: Problem, homework task.

**Quiz deck**:
The collection of quiz cards for one chapter.
_Avoid_: Learning set.

**Quiz attempt**:
One complete set of the student's answers to a quiz deck, with a score and a pass result. A quiz attempt passes when at least 80 percent of its answers are correct.
_Avoid_: Problem attempt, test run.

### Work and results

**Attempt**:
The student's work on one problem, with notes and one or more approaches. An attempt can be a draft or a saved attempt.
_Avoid_: Submission, test run, quiz attempt.

**Draft**:
An editable attempt whose changes are saved as the student works. Each problem has at most one draft.
_Avoid_: Unsaved attempt.

**Saved attempt**:
A finalized attempt kept in the problem's work history, with fixed content. Saving an attempt and accepting it are separate outcomes.
_Avoid_: Draft save, accepted attempt.

**Approach**:
One solution method within an attempt, with its reasoning and code.
_Avoid_: Attempt, submission.

**Accepted attempt**:
A saved attempt recorded as a successful solution in the notebook. Acceptance is separate from homework completion and current understanding.
_Avoid_: Completed homework task.

**Solved problem**:
A problem with at least one accepted attempt. It stays solved when the student needs more practice or the parent requests another attempt.
_Avoid_: Mastered problem.

**Understanding**:
The recorded assessment for a problem or an attempt: needs practice, with help, or independent. A problem's current understanding can change while it stays solved.
_Avoid_: Acceptance, homework completion.

**Test run**:
A practice execution of one approach against the problem's standard and own tests. Its result is separate from attempt acceptance.
_Avoid_: Submission, acceptance check.

**Acceptance check**:
The hidden-test evaluation of an attempt for a problem in a learning set. A successful check accepts the attempt and completes its active homework task, if any.
_Avoid_: Test run, homework review.

### Recall and feedback

**Recall**:
Practice on a problem before revealing saved work, followed by a recorded understanding assessment. Recall updates the problem's understanding and optional next recall date.
_Avoid_: Homework review, review without context.

**Homework review**:
The parent's evaluation of a submission, with a decision to complete the homework task or request another attempt.
_Avoid_: Recall, review without context.

**Tutor chat**:
The student's private conversation with the AI tutor about one problem or one learning set. Chapters in the same learning set share that set's tutor chat.
_Avoid_: Homework feedback, parent discussion.
