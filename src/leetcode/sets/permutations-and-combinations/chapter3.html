В главе 2 вы научились перебирать варианты. В этой главе два приёма: как не получить одинаковые ответы и как остановить ветку, которая не даст ответа.

1. Одинаковые ответы

Возьмите список [1, 2, 2]. Постройте все подмножества шаблоном из главы 2. Получится 8 списков:

[], [1], [1, 2], [1, 2, 2], [1, 2], [2], [2, 2], [2]

Списки [1, 2] и [2] встречаются по два раза. Для программы две двойки это разные предметы. Для ответа они одинаковые. Разных подмножеств только 6. Задача просит именно 6, без повторов.

2. Сортировка и пропуск на одном уровне

Сначала отсортируйте список. Тогда одинаковые числа стоят рядом. Потом на одном уровне дерева берите каждое число только один раз. Уровень это один проход цикла for.

nums.sort()    # один раз, до первого вызова
for i in range(start, len(nums)):
    if i > start and nums[i] == nums[i - 1]:
        continue    # на этом уровне такое число уже брали
    path.append(nums[i])
    dfs(i + 1, path)
    path.pop()

Почему i > start, а не i > 0? Пример: список [1, 2, 2], путь [2]. Следующий уровень начинается со start = 2. Там nums[2] == nums[1], но i == start. Это первая двойка на своём уровне. Её нужно взять, иначе не получится [2, 2]. Пропускаем только вторую и следующие копии на том же уровне.

Проверка: [1, 2, 2] с пропуском даёт 6 подмножеств: [], [1], [1, 2], [1, 2, 2], [2], [2, 2].

3. Перестановки с повторами

Список [1, 1, 2]. Без пропуска получится 6 перестановок, но разных только 3: [1, 1, 2], [1, 2, 1], [2, 1, 1].

В перестановках нет start. Цикл всегда идёт с нуля, а занятые числа отмечает список used. Поэтому правило другое: одинаковые числа берём по порядку. Вторую единицу можно взять, только если первая уже взята.

nums.sort()    # один раз, до первого вызова
for i in range(len(nums)):
    if used[i]:
        continue
    if i > 0 and nums[i] == nums[i - 1] and not used[i - 1]:
        continue    # такое же число слева ещё свободно
    used[i] = True
    path.append(nums[i])
    dfs(path)
    path.pop()
    used[i] = False

Проверка: [1, 2, 2, 3] даёт 12 перестановок. Без правила было бы 24.

4. Отсечение: остановите ветку заранее

Задача Combination Sum: даны числа [2, 3, 6, 7] и цель 7. Нужны все наборы с суммой 7. Одно число можно брать много раз. Ответ: [2, 2, 3] и [7].

Два отличия от сочетаний из главы 2. Первое: число можно взять снова, поэтому глубже передаём start = i, а не i + 1. Меньшие числа при этом не берём, и набор [3, 2, 2] не появится второй раз. Второе: если число больше остатка, ветка бесполезна. Остановить такую ветку до вызова это и есть отсечение.

Отсортируйте числа. Тогда, если число больше остатка, все следующие числа тоже больше. Можно сделать break, а не continue.

candidates.sort()    # один раз, до первого вызова
def dfs(start, remain, path):
    if remain == 0:
        result.append(path[:])
        return
    for i in range(start, len(candidates)):
        if candidates[i] > remain:
            break    # все следующие числа тоже больше
        path.append(candidates[i])
        dfs(i, remain - candidates[i], path)
        path.pop()

Для [2, 3, 6, 7] и цели 7 функция вызывается 10 раз. Без проверки candidates[i] > remain было бы 28 вызовов.

5. Скобки

Задача Generate Parentheses: дано n пар скобок, нужны все правильные строки. При n = 2 это (()) и ()(). При n = 3 строк 5:

((())), (()()), (())(), ()(()), ()()()

Строку строим по одному символу. Два правила отсекают все плохие ветки. Открыть скобку можно, пока opened < n. Закрыть можно, пока closed < opened: каждой закрывающей нужна открытая перед ней.

def dfs(s, opened, closed):
    if len(s) == 2 * n:
        result.append(s)
        return
    if opened < n:
        dfs(s + '(', opened + 1, closed)
    if closed < opened:
        dfs(s + ')', opened, closed + 1)

Без правил при n = 3 было бы 2 · 2 · 2 · 2 · 2 · 2 = 64 строки из 6 скобок. Правила оставляют 5.

6. Перебор знаков

Codeforces 1097B. Стрелка кодового замка стоит на нуле. Даны n поворотов в градусах, например 10, 20, 30. Каждый поворот делаем по часовой стрелке или против. Нужно узнать, может ли стрелка вернуться на ноль.

Каждому повороту ставим знак плюс или минус. Это как подмножества: взять с плюсом или с минусом. Вариантов 2 · 2 · 2 = 8 при n = 3. В задаче n не больше 15, это 32768 вариантов. Компьютер переберёт их мгновенно.

Полный оборот это 360 градусов. Стрелка на нуле, когда сумма делится на 360. Для 10, 20, 30: 10 + 20 − 30 = 0, ответ YES. Для 10, 10, 10 ни одна из 8 сумм не делится на 360, ответ NO.

def dfs(i, total):
    if i == n:
        return total % 360 == 0
    return dfs(i + 1, total + a[i]) or dfs(i + 1, total - a[i])

7. Что нужно запомнить

  • Одинаковые ответы появляются, когда во входе есть одинаковые числа. Сначала sort().
  • Подмножества и сочетания: пропуск при i > start and nums[i] == nums[i - 1].
  • Перестановки: пропуск, если такое же число слева ещё не использовано.
  • Отсечение: ветка не может дать ответ, остановите её до вызова. После сортировки это break.
  • Скобки: открыть, пока opened < n; закрыть, пока closed < opened.

8. Как решать задачи этой главы

  1. Прочитайте условие. Выпишите маленький пример и его ответ на бумаге.
  2. Решите, что перебираете: подмножества, перестановки или наборы с суммой. Возьмите шаблон из главы 2.
  3. Добавьте правило пропуска или отсечение. Проверьте код на своём примере, потом отправляйте.
