В первой главе вы считали, сколько есть вариантов. В этой главе вы научитесь выписывать сами варианты. Для этого есть один шаблон на Python. Он решает четыре задачи этой главы.

1. Когда нужны сами варианты

Вы знаете, что из 3 предметов можно собрать 8 подмножеств. Но задача часто просит другое: выпишите все 8. Например, LeetCode 78 ждёт эти 8 списков, в любом порядке: [[], [1], [1, 2], [1, 2, 3], [1, 3], [2], [2, 3], [3]].

Число вариантов подсказывает, сколько строк должно быть в ответе. Это хорошая проверка. Сам список строит программа. Такой способ называют перебор.

2. Дерево вариантов

Возьмём список [1, 2, 3]. Про каждое число решаем: взять или не взять.

  • Число 1: взять или нет. Это 2 ветки.
  • В каждой ветке число 2: взять или нет. Уже 4 ветки.
  • В каждой из них число 3: взять или нет. Всего 8 веток.

Получилось дерево. Корень это пустой список. Каждый шаг вниз это одно решение. Лист это конец ветки: все числа рассмотрены. Каждый лист это одно подмножество. Листьев 8, подмножеств тоже 8: 2 · 2 · 2 = 8.

Программа идёт по дереву так: спускается по левой ветке до листа, возвращается на шаг назад, пробует другую ветку. Это и есть перебор с возвратом.

3. Рекурсия простыми словами

Рекурсия это функция, которая вызывает сама себя. Для дерева это удобно. Функция делает один шаг вниз, а дальше просит саму себя сделать остальное. Функцию, которая идёт по дереву, назовём dfs.

У такой функции два правила. Первое: есть условие остановки, например «все числа рассмотрены». Второе: каждый вызов делает задачу меньше, например переходит к следующему числу. Без первого правила функция не остановится.

4. Шаблон: выбрать, пойти глубже, отменить

Список path это путь от корня до текущей точки дерева. В цикле делаем три шага.

  1. Выбрать: path.append(x).
  2. Пойти глубже: dfs(...).
  3. Отменить: path.pop().

Третий шаг нужен, чтобы вернуть path в то состояние, какое было до выбора. Тогда следующий шаг цикла начинает с чистого места.

Ещё одна деталь. Результат сохраняем как path[:], то есть копию. Если сохранить сам path, все строки ответа будут указывать на один и тот же список. В конце он пустой. Для [1, 2, 3] вы получите восемь пустых списков.

5. Подмножества

LeetCode 78. Код строит другое дерево: из каждой точки ветки идут только к числам правее, это индекс start. Тогда [2, 1] после [1, 2] не появится. В таком дереве каждая точка это подмножество, поэтому сохраняем path при каждом вызове, а не только в листьях.

def subsets(nums):
    res = []
    def dfs(start, path):
        res.append(path[:])
        for i in range(start, len(nums)):
            path.append(nums[i])
            dfs(i + 1, path)
            path.pop()
    dfs(0, [])
    return res

Для [1, 2, 3] функция выдаёт 8 списков в таком порядке: [], [1], [1, 2], [1, 2, 3], [1, 3], [2], [2, 3], [3]. Для 4 чисел будет 16 списков.

6. Перестановки

LeetCode 46. Теперь порядок важен: [1, 2, 3] и [2, 1, 3] это разные ответы. Поэтому цикл каждый раз идёт с нуля. Чтобы не взять одно и то же число дважды, заводим список used. Он помечает индексы, которые уже лежат в path.

def permute(nums):
    res = []
    used = [False] * len(nums)
    def dfs(path):
        if len(path) == len(nums):
            res.append(path[:])
            return
        for i in range(len(nums)):
            if used[i]:
                continue
            used[i] = True
            path.append(nums[i])
            dfs(path)
            path.pop()
            used[i] = False
    dfs([])
    return res

Отмена здесь из двух строк: path.pop() и used[i] = False. Ответ сохраняем только в листе, когда длина path равна длине nums. Для 3 чисел будет 3! = 6 ответов, для 4 чисел 4! = 24.

7. Сочетания

LeetCode 77. Нужны все наборы из k чисел от 1 до n, порядок не важен. Это шаблон подмножеств с одним отличием: сохраняем только пути длины k.

def combine(n, k):
    res = []
    def dfs(start, path):
        if len(path) == k:
            res.append(path[:])
            return
        for x in range(start, n + 1):
            path.append(x)
            dfs(x + 1, path)
            path.pop()
    dfs(1, [])
    return res

Для n = 4 и k = 2 получаем 6 наборов: [1, 2], [1, 3], [1, 4], [2, 3], [2, 4], [3, 4]. Это C(4, 2) = 6 из первой главы.

8. Буквы на телефоне

LeetCode 17. На кнопке 2 буквы abc, на кнопке 3 буквы def. Для строки "23" нужны все пары: ad, ae, af, bd, be, bf, cd, ce, cf. Это 3 · 3 = 9 строк.

Здесь каждая цифра это один уровень дерева. На уровне перебираем буквы этой цифры. Ответ сохраняем, когда дошли до конца строки.

KEYS = {'2': 'abc', '3': 'def', '4': 'ghi', '5': 'jkl',
        '6': 'mno', '7': 'pqrs', '8': 'tuv', '9': 'wxyz'}
def letters(digits):
    res = []
    def dfs(i, path):
        if i == len(digits):
            res.append(''.join(path))
            return
        for ch in KEYS[digits[i]]:
            path.append(ch)
            dfs(i + 1, path)
            path.pop()
    if digits:
        dfs(0, [])
    return res

Пустая строка даёт пустой список, это условие задачи. Для "234" будет 3 · 3 · 3 = 27 строк.

9. Что нужно запомнить

  • Три шага в цикле: выбрать, пойти глубже, отменить.
  • Сохраняйте копию: path[:], а не path.
  • Порядок не важен: цикл от start. Порядок важен: цикл с нуля и список used.
  • Подмножества сохраняем в каждой точке, перестановки и сочетания только в листе.
  • Число ответов из первой главы проверяет вашу программу: 8, 24, 6, 9.

10. Как решать задачи этой главы

  1. Прочитайте условие и решите, важен ли порядок.
  2. Посчитайте на бумаге, сколько ответов должно быть для маленького примера.
  3. Выпишите шаблон и выберите: start или used, сохранять везде или в листе.
  4. Запустите на примере и сравните число ответов с бумагой.
