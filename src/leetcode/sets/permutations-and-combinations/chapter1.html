1 Count before you code

  • Combinatorics
  • Complexity

Before you write a search, count the answers. Each item is in a subset or not in it, so n items have 2n subsets. n different items have n! orders. n! (n factorial) is n × (n - 1) × ... × 1. A program that lists all answers does at least one step for each answer. So the count tells you if a solution that lists all answers is fast enough.

Rule for LeetCode limits. Read the limits in the problem first.

  • If n is about 9 or less, a search over all orders (n!) is usually fast enough. In Python, 10! orders take some seconds and a lot of memory.
  • If n is about 20 or less, a search over all subsets (2n) is usually fast enough.

The product rule

You make k independent choices. Choice 1 has a1 options, choice 2 has a2 options, and so on. Then the number of results is a1 × a2 × ... × ak.

Worked example: Letter Combinations of a Phone Number

The digit 2 gives "abc" and the digit 3 gives "def". The input "23" has 2 choices with 3 options each. The result has 3 × 3 = 9 strings.

Two questions select the formula

The product rule gives the first two rows. For P(5, 3), the first place has 5 options, the second place has 4 options and the third place has 3 options. So P(5, 3) = 5 × 4 × 3 = 60. For a sequence, each place has 5 options. So the count is 5 × 5 × 5 = 125.

Facts that you use often

  • n! = n × (n - 1) × ... × 1. This is P(n, n): all orders of all n items. By definition, 0! = 1.
  • C(n, k) = P(n, k) / k!. Each group of k items appears in k! different orders. Example: 60 / 3! = 60 / 6 = 10.
  • Repeated values: equal values can change places and the list stays the same. So divide n! by the number of orders of each group of equal values. The formula is n! / (a! × b! × ...), where a, b, ... are the counts of each repeated value. "BOOK" has two O letters, so it gives 4! / 2! = 12 words. The list [1, 1, 2] gives 3! / 2! = 3 orders.
  • The sum of C(n, k) for k = 0 to n is 2n. Each subset has exactly one size.
  • C(n, k) = C(n - 1, k - 1) + C(n - 1, k). You take the first item and choose k - 1 from the rest, or you skip it and choose k from the rest.

Worked example: Unique Paths

A robot moves on a grid with 3 rows and 7 columns. It moves only down or right, from the top-left cell to the bottom-right cell. Each path has 2 down moves and 6 right moves: 8 moves in total. When you know which 2 of the 8 moves go down, you know the path. So the count is C(8, 2) = 28.

Python has these formulas in the math module. Use them to check the counts that you calculate by hand.

from math import comb, factorial, perm

print(perm(5, 3), 5 ** 3, comb(5, 3), comb(5 + 3 - 1, 3))
print(perm(5, 3) // factorial(3))
print(factorial(4) // factorial(2))
print(sum(comb(5, k) for k in range(6)), 2 ** 5)
print(comb(8, 2))
