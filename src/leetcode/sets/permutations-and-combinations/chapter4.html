В этой главе вы не строите все варианты. Вы находите один нужный вариант или только их число.

1. Словарный порядок

Запишите все перестановки чисел 1, 2, 3 так, как слова стоят в словаре. Сначала сравниваем первую цифру. Если она равна, сравниваем вторую. И так далее.

123  132  213  231  312  321

Это словарный порядок. В нём у каждой перестановки есть номер: 123 первая, 132 вторая, 321 шестая. Правило одно: меньшее идёт раньше, и для букв тоже.

Проверьте себя: что идёт после 1 3 2? Ответ: 2 1 3.

2. Следующая перестановка

LeetCode 31. Дана перестановка. Нужна следующая по словарному порядку. Строить все n! вариантов долго. Сделаем три шага на примере 1 2 5 4 3.

  1. Идите справа налево. Найдите первое число, которое меньше своего правого соседа. Хвост 5 4 3 убывает, а 2 < 5. Это число 2.
  2. Справа от 2 найдите самое правое число, которое больше 2. Это 3. Поменяйте их местами: 1 3 5 4 2.
  3. Хвост после 3 стоит по убыванию: 5 4 2. Переверните его: 1 3 2 4 5.

Почему так? Хвост 5 4 3 уже самый большой из возможных. Чтобы перестановка стала больше, число перед хвостом заменяем на самое маленькое число из хвоста, которое больше него. Потом хвост делаем самым маленьким: переворачиваем.

Если на шаге 1 ничего не нашлось, как в 3 2 1, то это последняя перестановка. Переверните весь массив: 1 2 3.

def next_permutation(a):
    i = len(a) - 2
    while i >= 0 and a[i] >= a[i + 1]:
        i -= 1
    if i >= 0:
        j = len(a) - 1
        while a[j] <= a[i]:
            j -= 1
        a[i], a[j] = a[j], a[i]
    # i == -1 reverses the whole list: the last permutation
    a[i + 1:] = a[i + 1:][::-1]

3. Пути в сетке

LeetCode 62. Сетка из 2 строк и 3 столбцов. Робот стоит в левом верхнем углу и идёт в правый нижний. Ходить можно только вправо (R) или вниз (D). Сколько есть путей?

Каждый путь это строка из букв. Вправо нужно 2 шага, вниз 1 шаг. Всего 3 шага. Пути: RRD, RDR, DRR. Их 3.

Путь задаёт место буквы D. Мы выбираем 1 место из 3 без порядка, это сочетание из главы 1: C(3, 1) = 3.

Для сетки из m строк и n столбцов: шагов вниз m − 1, шагов вправо n − 1, всего m + n − 2. Ответ C(m + n − 2, m − 1). Сетка 3 на 3: C(4, 2) = 6.

Проверка таблицей. В клетку можно прийти сверху или слева. Число путей в клетку равно сумме путей в клетку сверху и в клетку слева. В первой строке и в первом столбце по 1 пути.

1111
1234
13610
141020

Клетка в 3-й строке и 3-м столбце даёт 6, как и формула. Код хранит только одну строку таблицы и пересчитывает её m − 1 раз. Формулу даёт math.comb(m + n - 2, m - 1).

def unique_paths(m, n):
    row = [1] * n
    for _ in range(m - 1):
        for j in range(1, n):
            row[j] += row[j - 1]
    return row[-1]

4. k-я перестановка

LeetCode 60. Даны n = 3 и k = 3. Нужна третья перестановка в словарном порядке. Из раздела 1 ответ 213. Получим его без списка всех.

Перестановки идут блоками по первой цифре. С цифрой 1: 123, 132. С цифрой 2: 213, 231. С цифрой 3: 312, 321. В каждом блоке (n − 1)! = 2! = 2 перестановки.

Нумеруем с нуля: k − 1 = 2. Номер блока: 2 // 2 = 1. Доступные цифры 1, 2, 3, берём цифру с номером 1, это 2. Остаток 2 % 2 = 0. Остались цифры 1, 3, блок теперь из 1! = 1 перестановки. 0 // 1 = 0, берём 1. Осталась 3. Ответ 213.

Для n = 4 в каждом блоке 3! = 6 перестановок. При k = 9: (9 − 1) // 6 = 1, первая цифра 2. Дальше остаток 8 % 6 = 2 и цифры 1, 3, 4. Блок теперь 2! = 2: 2 // 2 = 1, берём 3. Остаток 0: берём 1, потом 4. Ответ 2314.

from math import factorial
def kth_permutation(n, k):
    digits = list(range(1, n + 1))
    k -= 1
    out = ''
    for size in range(n - 1, -1, -1):
        block = factorial(size)
        out += str(digits.pop(k // block))
        k %= block
    return out

5. Ферзи: задача-вызов

LeetCode 51. Доска n на n. Поставьте n ферзей так, чтобы никакие два не били друг друга. Ферзь бьёт по строке, по столбцу и по двум диагоналям.

Ставим по одному ферзю в строку: сначала в строку 0, потом в строку 1, и так далее. Тогда два ферзя никогда не стоят в одной строке. Это перебор из главы 2: выбрать столбец, пойти глубже, отменить.

Строку ферзя назовём r, столбец c. Клетку записываем как (r, c). Столбцы и диагонали храним в трёх множествах. cols: занятые столбцы. diag1: разности r − c. diag2: суммы r + c. Посмотрите на клетки (0, 1), (1, 2), (2, 3): они на одной диагонали, и r − c везде равно −1. Клетки (0, 3), (1, 2), (2, 1) на другой диагонали, и r + c везде равно 3.

Занятый столбец или диагональ отсекают ветку, как в главе 3. Для n = 4 есть 2 ответа, для n = 8 их 92.

def solve_n_queens(n):
    cols, diag1, diag2, result = set(), set(), set(), []
    def place(r, board):
        if r == n:
            result.append(board[:])
            return
        for c in range(n):
            if c in cols or r - c in diag1 or r + c in diag2:
                continue
            cols.add(c)
            diag1.add(r - c)
            diag2.add(r + c)
            board.append(c)
            place(r + 1, board)
            board.pop()
            cols.remove(c)
            diag1.remove(r - c)
            diag2.remove(r + c)
    place(0, [])
    return result  # column of the queen in each row

6. Что нужно запомнить

  • Словарный порядок: сравниваем первую цифру, при равенстве вторую.
  • Следующая перестановка: найти спад справа, обменять, перевернуть хвост.
  • Пути в сетке: выбираем места для шагов вниз, C(m + n − 2, m − 1).
  • k-я перестановка: блоки по (n − 1)!, и (k − 1) // (n − 1)! даёт первую цифру.
  • Ферзи: по одному в строку, множества столбцов и двух диагоналей.
