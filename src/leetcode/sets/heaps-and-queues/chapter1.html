Queue отдаёт элементы в порядке прихода, а deque работает с обоими концами, и оба делают это за O(1).

1. Queue: первым пришёл, первым ушёл

from collections import deque

q = deque()
q.append(5)
q.append(8)
q.append(2)          # q = [5, 8, 2]
print(q.popleft())   # вернёт 5, q = [8, 2]
q.append(7)          # q = [8, 2, 7]
print(q.popleft())   # вернёт 8, q = [2, 7]

Число 5 пришло первым и ушло первым. Число 8 пришло вторым и ушло вторым. Так работает очередь в столовой: новый ученик встаёт в конец, а обед получает тот, кто стоит в начале.

Правило. Queue: кладём в конец, берём из начала. Первым пришёл, первым ушёл.

Начало queue называют головой, конец хвостом. Последние два кадра рисунка показывают deque, о нём раздел 3.

2. Почему не список

Список тоже умеет забирать из начала: a.pop(0). Возьмите a = [5, 8, 2, 7, 4]. Вызов pop(0) забирает 5, и каждое из 4 чисел правее сдвигается на одну ячейку влево.

В списке из 100 000 чисел первый pop(0) сдвигает 99 999 чисел, второй 99 998, и так до нуля. Всего 100 000 · 99 999 / 2 = 4 999 950 000 сдвигов. На обычном компьютере это около 0,7 с, у deque.popleft около 0,004 с. Python в браузере медленнее, а лимит 2 с на пример, 3 с на скрытый тест.

Можно не удалять число, а двигать номер головы: head += 1. Но тогда список не уменьшается. Deque решает обе проблемы: popleft() ничего не сдвигает и освобождает память.

Правило. Для queue берите deque: popleft() работает за O(1), а list.pop(0) за O(n).

3. Deque: два конца

from collections import deque

d = deque([2, 4, 5])
d.appendleft(1)      # d = [1, 2, 4, 5]
print(d.pop())       # вернёт 5, d = [1, 2, 4]
d.append(7)          # d = [1, 2, 4, 7]
print(d.popleft())   # вернёт 1, d = [2, 4, 7]
ВызовЧто делаетВремя
d.append(x)кладёт x в конецO(1)
d.appendleft(x)кладёт x в началоO(1)
d.pop()забирает с концаO(1)
d.popleft()забирает из началаO(1)
d[0], d[-1]читает концыO(1)
d[i] в серединеdeque хранит числа кусками, до середины идёт кусок за кускомO(n)

len(d) даёт длину, а цикл while d: идёт, пока deque не пуст. Вызов popleft() у пустого deque даёт ошибку, поэтому сначала проверяйте deque.

Правило. Deque быстрый на концах: четыре метода работают за O(1). Если нужен доступ по номеру в середине, берите список.

4. Модель процесса: очередь за билетами

LeetCode 2073. tickets = [3, 1, 2]: человек 0 хочет 3 билета, человек 1 один, человек 2 два. Один билет покупают за 1 секунду. После покупки человек встаёт в конец, если ему нужны ещё билеты. Когда человек k = 0 купит последний билет?

from collections import deque

def time_required(tickets, k):
    q = deque(range(len(tickets)))   # номера людей
    time = 0
    while True:
        p = q.popleft()
        tickets[p] -= 1
        time += 1
        if p == k and tickets[p] == 0:
            return time
        if tickets[p] > 0:
            q.append(p)

print(time_required([3, 1, 2], 0))   # 6

В queue лежат номера людей, а не числа билетов: так видно, где человек k. Каждую секунду продаётся ровно один билет. Значит, ответ равен числу билетов, которые продали к моменту, когда человек k купил последний билет. Здесь это 3 + 1 + 2 = 6. В задаче найдите тот же ответ одной суммой: сколько билетов успеет купить человек, который стоит до k, и человек после k?

Иногда процесс может крутиться без конца. В задаче 1700 ученик не берёт бутерброд и встаёт в конец. Если очередь прошла полный круг и никто не взял бутерброд, процесс встал.

Правило. Модель процесса: взяли из начала, сделали шаг, вернули в конец, если элемент ещё нужен. Заранее решите, когда процесс кончается.

5. Круг и rotate

LeetCode 1823. Шесть друзей сидят по кругу, выбывает каждый третий. Храните круг в deque: тот, с кого начинается счёт, стоит в начале. На «раз» и «два» друзья 1 и 2 остаются в игре и уходят в конец. На «три» друг 3 выбывает.

from collections import deque

d = deque([1, 2, 3, 4, 5, 6])
d.rotate(-2)         # d = [3, 4, 5, 6, 1, 2]
print(d.popleft())   # вернёт 3, d = [4, 5, 6, 1, 2]

Правило. d.rotate(-m) переносит m элементов из начала в конец. d.rotate(m) переносит m элементов из конца в начало. d.rotate(-m) делает m переносов, поэтому стоит O(m).

Следующие круги сделайте сами в задаче 1823. Кто победит при n = 6 и k = 3?

6. Что нужно запомнить

  • Queue: append кладёт в конец, popleft берёт из начала.
  • q.pop() берёт с конца: последний пришёл, первым ушёл. deque([5, 8, 2]).pop() вернёт 2.
  • list.pop(0) сдвигает все числа. 100 000 вызовов делают почти 5 миллиардов сдвигов.
  • Deque работает с обоими концами за O(1), с серединой за O(n).
  • popleft() у пустого deque даёт ошибку. Проверяйте: while q: или if q:.
  • Следите за знаком у rotate: минус переносит из начала в конец.
  • queue.Queue нужен, когда несколько частей программы работают одновременно. В задачах берите deque.

7. Как решать задачи этой главы

  1. Решите, что стоит в queue: номера людей, ученики, места карт.
  2. Запишите один шаг: что берём из начала, что делаем, куда кладём.
  3. Решите, когда процесс кончается. Если он может крутиться по кругу, считайте ходы без изменений.
  4. Прогоните модель на примере из условия на бумаге. Только потом пишите код.
  5. Посчитайте шаги. Каждый шаг на deque стоит O(1), а лимит 2 с на пример, 3 с на скрытый тест.
