Монотонный дек находит максимум каждого окна за один проход: каждый номер входит в дек один раз и выходит не больше одного раза.

1. Задача: максимум каждого окна

Дан массив a = [2, 7, 3, 1, 5, 2, 6, 4] и k = 3. Окно из k соседних чисел идёт слева направо. Для каждого окна нужен его максимум: ответ [7, 7, 5, 5, 6, 6].

Перебор читает каждое окно целиком.

Окон n − k + 1, в каждом k чисел. При n = 100 000 и k = 50 000 это около 2,5 · 109 чтений, а лимит 2 с на пример, 3 с на скрытый тест. Python столько не успеет.

2. Куча из главы 2

Кладём в кучу пары (−x, i), и вершина даёт наибольшее число в куче. На шаге i = 4 вершина (−7, 1), но номер 1 ≤ 4 − 3 уже вне окна: выбрасываем её, и новая вершина (−5, 4) даёт 5. Старые пары ниже вершины ждут, пока сами станут вершиной, и куча растёт до n пар: время O(n log n), а дек даст O(n).

3. Лесенка

На шаге i = 3 в деке 7, 3, 1. Пришло 5. Числа 3 и 1 старше пятёрки и меньше её: пока они в окне, 5 тоже в окне. Максимумом они уже не станут.

Правило. Пришло x. Каждое число y ≤ x перед ним больше не нужно: пока y в окне, x тоже в окне и не меньше y. Выбросьте такие числа сразу. Тогда значения в деке убывают от начала к концу, как лесенка.

4. Дек шаг за шагом

В деке храним номера, а не числа: по номеру видно, что число вышло из окна. На шаге i окно это номера от i − k + 1 до i, поэтому номер dq[0] ≤ i − k уже вне окна. Шаг такой: сзади выбрасываем номера, где a[dq[-1]] ≤ x, кладём i, спереди убираем вышедший номер. С шага i = k − 1 ответ a[dq[0]].

Каждый номер входит в дек один раз и выходит не больше одного раза. Поэтому операций не больше 2n, и время O(n).

5. Код

from collections import deque

a = [2, 7, 3, 1, 5, 2, 6, 4]
k = 3
dq = deque()
res = []
for i, x in enumerate(a):
    while dq and a[dq[-1]] <= x:
        dq.pop()
    dq.append(i)
    if dq[0] <= i - k:
        dq.popleft()
    if i >= k - 1:
        res.append(a[dq[0]])
print(res)   # [7, 7, 5, 5, 6, 6]

Правило. Сзади выбрасываем слабых, спереди выбрасываем старых. Для минимума сзади выбрасываем числа ≥ x, и значения в деке растут.

6. Два дека: max − min ≤ limit

LeetCode 1438: найдите самое длинное окно, где max − min ≤ limit. Длина окна теперь меняется. Правая граница r идёт вперёд, левая l догоняет, как в наборе «Два указателя». Один дек даёт максимум окна, второй минимум. Пример: nums = [4, 8, 5, 6, 7, 1, 2], limit = 3.

При r = 5 пришло число 1, и 8 − 1 > 3. Левая граница идёт до номера 5, и из начала дека максимумов уходят номера 1 и 4, то есть числа 8 и 7. Ответ 4: окно [8, 5, 6, 7].

while nums[mx[0]] - nums[mn[0]] > limit:
    l += 1
    if mx[0] < l:
        mx.popleft()
    if mn[0] < l:
        mn.popleft()

7. Сколько отрезков подходит

LeetCode 2762 спрашивает число отрезков, где max − min ≤ 2. Возьмите nums = [5, 4, 2, 4]. При r = 2 левая граница l = 1, и подходят отрезки [4, 2] и [2]: их r − l + 1 = 2. Отрезок [5, 4, 2] не подходит, ведь 5 − 2 = 3. Сумма по всем r: 1 + 2 + 2 + 3 = 8.

Правило. Если отрезок от l до r подходит, то подходят и все отрезки внутри него. Поэтому для правой границы r подходят r − l + 1 отрезков, где l самая левая подходящая граница. Ответ может дойти до 5 000 050 000, это около 5 · 109.

8. Окно с суммой: роботы

LeetCode 2398: окно роботов стоит max(chargeTimes) + k · sum(runningCosts), где k длина окна. Максимум даёт дек, как в разделе 4. Сумму держите числом: при новом r прибавьте runningCosts[r], при сдвиге l вычтите runningCosts[l]. Пока окно не пустое и стоимость больше budget, двигайте l.

Если окно дороже бюджета, то любое окно, которое его содержит, тоже дороже: max не меньше, а k и sum больше. Поэтому l не идёт назад, и время O(n).

9. Что нужно запомнить

  • В деке номера, а не числа: номер dq[0] ≤ i − k уже вне окна.
  • Сзади уходят числа ≤ x, спереди уходит номер, который вышел из окна.
  • Окно длины k даёт n − k + 1 ответов, первый на шаге i = k − 1.
  • Для минимума знак зеркальный: сзади уходят числа ≥ x.

10. Как решать задачи этой главы

  1. Найдите окно: отрезок подряд, который идёт слева направо.
  2. Решите, что нужно знать об окне. Для максимума и минимума берите дек номеров, для суммы обычное число.
  3. Окно длины k сдвигайте на 1. Окно переменной длины: r идёт вперёд, l догоняет, пока условие нарушено.
  4. Прогоните дек на примере из условия на бумаге: какие номера лежат в нём после каждого шага.
