1. Сначала посчитай действия

n - число элементов входного списка. Это не значение самого большого числа. Для [3, 1, 4, 2] имеем n = 4. Найдём максимум, как в первой главе про Permutations и Combinations.

def maximum(a):
    best = a[0]
    for i in range(1, len(a)):
        if a[i] > best:
            best = a[i]
    return best

print(maximum([3, 1, 4, 2, 8, 5, 7, 6]))

Вход непустой. Первое число сразу становится best. Сравнения начинаются со второго. Для четырёх чисел нужны три сравнения. Считаем работу внутри функции; создание примера и print нужны только для запуска.

2. Что означает O(n)

При большем входе программа делает больше работы. Big-O описывает верхнюю границу её роста. Здесь используем обычную наиболее точную оценку из O(1), O(n), O(n²). Время оцениваем в худшем случае. Числа считаем небольшими: сложение, сравнение и чтение по индексу требуют постоянной работы.

O(1): число действий ограничено постоянным числом, независимо от n. O(n): работа растёт примерно вместе с n. O(n²): при удвоении большого входа работы становится примерно в четыре раза больше.

У максимума n - 1 сравнений и не больше n - 1 обновлений. Все действия вместе растут как n. Постоянные множители и слагаемые не меняют этот рост. O(n) не означает ровно n действий или n секунд. O(1) тоже может включать несколько действий.

3. Память считаем отдельно

Дополнительная память - наибольший объём рабочих данных, которые нужны одновременно, сверх уже данного входа. В maximum это i и best. Их значения меняются, но новые переменные на каждом шаге не накапливаются. Результат здесь одно число; память ответа считаем отдельно.

b = a[:]

Эта строка создаёт копию списка. При n = 4 копия хранит 4 ссылки на элементы, при n = 8 уже 8. Одна строка кода может делать много работы: копирование требует O(n) времени.

4. Два прохода складываем

def describe(a):
    total = 0
    for x in a:
        total += x
    positive = 0
    for x in a:
        if x > 0:
            positive += 1
    return total, positive

print(describe([3, -1, 4, 2]))

Сначала проходят все n чисел, затем ещё раз все n чисел. Получаем n + n = 2n посещений. При удвоении n посещений тоже вдвое больше. Два последовательных прохода не дают n².

5. Все пары и Two Pointers

В Two Sum ищем два разных элемента с нужной суммой. Сначала проверим все пары. Этот код считает подходящие пары и не останавливается после первой.

def count_pairs(a, target):
    count = 0
    for i in range(len(a)):
        for j in range(i + 1, len(a)):
            if a[i] + a[j] == target:
                count += 1
    return count

print(count_pairs([2, 7, 11, 15], 9))

У первого элемента три партнёра справа, у второго два, у третьего один. Пару с самим собой и повторную пару не проверяем.

Для n элементов проверок n(n - 1)/2 = (n² - n)/2. При большом n рост определяет n². Деление на 2 и вычитание n не меняют квадратичный рост.

Теперь знакомый Two Pointers. Вход уже упорядочен по возрастанию, повторы допустимы. Нужна любая подходящая пара. При малой сумме двигаем l, при большой двигаем r.

def two_sum(a, target):
    l, r = 0, len(a) - 1
    while l < r:
        s = a[l] + a[r]
        if s == target:
            return [l + 1, r + 1]
        if s < target:
            l += 1
        else:
            r -= 1
    return None

print(two_sum([2, 7, 11, 15], 9))

Расстояние между указателями сначала n - 1. Каждая неудача уменьшает его на один. Успех завершает поиск. Для n ≥ 2 проверок суммы не больше n - 1: оба указателя вместе проходят это расстояние.
