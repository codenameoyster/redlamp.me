Каждая проверка n % p === 0 считается отдельно: одна в if, затем все в while, включая последнюю неудачную. Диапазон кандидатов объединяет проверки без делений. Строка «в ответ» добавляет оставшийся простой множитель без проверки % и без деления.

Время и память Trial Division

N - исходное значение; r - оставшееся значение после делений; f - число разных простых множителей в ответе. Переменная n в коде хранит именно r. Кандидаты идут от 2, пока p² ≤ r.

Если число составное, хотя бы один множитель не больше его квадратного корня. Поэтому после проверки всех допустимых кандидатов остаток r > 1 прост. Он не обязан превышать √N: у 12 после делений на 2 остаётся 3, а 3 < √12.

Время: не больше ⌊√N⌋−1 кандидатов и ⌊log₂ N⌋ успешных делений. Повторы проверок при найденных множителях добавляют ещё O(log N) операций. Итого O(√N) арифметических операций в худшем случае. Простое 998244353 даёт 31595−2+1 = 31594 кандидата и столько же проверок %.

Деления уменьшают r и границу цикла. Для 360: 360 → 45 → 5. Проверяются только 2 и 3. Для 2 нужны 1+4 = 5 проверок %, для 3 ещё 1+3 = 4: всего 9 проверок и 5 делений. Остаток 5 добавляется в ответ.

Дополнительная память алгоритма: O(1) скалярных переменных, без входа и ответа. Ответ: O(f) пар «простой множитель, степень». Таблица шагов страницы хранит ещё O(f) строк: соседние неудачные кандидаты объединены. История хранит до 20 отдельных результатов; её память равна сумме размеров этих ответов.

Значение и длина входа: N здесь число, а не число цифр. При b = ⌊log₂ N⌋+1 бит оценка O(√N) равна O(2^(b/2)), то есть экспоненциальна по длине записи. Страница принимает числа до 999999999999, ниже предела точных целых JavaScript 2⁵³−1. Здесь считаем арифметику за O(1); для произвольно больших целых нужно учитывать размер чисел.

Другие варианты перебора

Только нечётные кандидаты: сначала убрать множитель 2, затем проверять 3, 5, 7 и далее. Для простого 998244353 это 1 проверяемый кандидат 2 и 15797 нечётных кандидатов, всего 15798 вместо 31594. Худший случай остаётся O(√N), дополнительное скалярное состояние - O(1).

Таблица простых: для многих запросов можно заранее построить простые до M = ⌊√Nmax⌋ методом Sieve of Eratosthenes за O(M log log M) времени и O(M) памяти. Один запрос перебирает до π(√N) кандидатов, где π(x) - число простых до x, плюс повторные деления. Подготовка и хранение таблицы оплачиваются отдельно.
