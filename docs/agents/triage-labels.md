# Triage labels

Use this mapping when a skill names a triage role.

| Role | Tracker label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer must evaluate the issue. |
| `needs-info` | `needs-info` | The reporter must provide more information. |
| `ready-for-agent` | `ready-for-agent` | The issue is fully specified for unattended agent implementation. |
| `ready-for-human` | `ready-for-human` | The issue requires human implementation. |
| `wontfix` | `wontfix` | The issue will not be implemented. |

Edit the Tracker label column to change the label names.
